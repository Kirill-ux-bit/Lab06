Загрузка процессора увеличивается  потому,что программа компелируется перед запуском, а также программа собирает данные о прцессоре и выводит их на экран.

## Контрольные вопросы
1) Файл - это статический набор данных, лежащий на диске и не потребляющий ресурсов ЦП.
  Процесс - это тот же код, но уже загруженный в оперативную память и выполняемый процессором в реальном времени.
2) Оперативная память нужна для временного хранения кода программы и данных, с которыми она работает. ОЗУ работает в сотни раз быстрее диска, что позволяет процессору быстро получать доступ к нужным данным.
3) Нужно найти процесс по имени. Если программа работает, она появится в списке и будет потреблять какой-то процент CPU, а также займёт определённый объём памяти в мегабайтах.
4) Процессор обрабатывает данные, чем больше и сложнее вычисления, тем больше вычислительных циклов ему требуется, что и отображается как рост загрузки.
5) Да остается. Процесс - это лишь временная копия файла в памяти. Исходный исполняемый файл на диске остаётся нетронутым и готовым к следующему запуску.
## Вывод
Программа запускается с накопителя HDD или SSD, где она хранится в виде статического файла. Затем операционная система загружает этот код и необходимые данные в оперативную память (RAM), так как процессор не может напрямую и быстро читать информацию с диска. В RAM программа превращается в активный процесс. После этого процессор (CPU) начинает считывать инструкции из оперативной памяти, выполнять вычисления и записывать результаты обратно в RAM. Таким образом, накопитель служит постоянным хранилищем, RAM - быстрой рабочей зоной, процесс - активной формой жизни программы, а CPU - исполнителем, который делает всю вычислительную работу.
